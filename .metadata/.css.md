**Use the screenshot as a visual reference for the design language—not as a template to copy.** Your frontend should retain the same level of polish, information density, card/grid structure, and security-dashboard feel, while changing the components and information architecture to match your actual SIH requirement.

## 1. Design Direction for Your AI

Give your frontend-generating AI this instruction:

> Build a **production-grade cybersecurity monitoring dashboard** inspired by the attached reference image, but **do not reproduce its layout, text, charts, or visual arrangement exactly**.
>
> The reference establishes the visual language:
>
> * premium enterprise SOC interface
> * dark navy security sidebar
> * warm off-white main workspace
> * white/cream elevated cards
> * purple as the primary accent
> * green/red/orange security status colors
> * dense but highly readable information architecture
> * rounded cards with subtle borders
> * minimal shadows
> * professional typography
> * real-time monitoring aesthetic
>
> Adapt the UI architecture to the **actual system requirements**. Prioritize operational information over decorative dashboard elements. Every visualization, metric, table, and action should correspond to a real system capability.
